# 平衡三进制转换器与计算器 (VSCode 扩展)

平衡三进制 ↔ 十进制 双向转换，支持任意精度和循环节检测；内置交互式计算器。

## 功能

| 命令 | 说明 | 快捷键 |
|---|---|---|
| `Ternary: 十进制 → 平衡三进制` | 输入十进制数，输出三进制 | — |
| `Ternary: 平衡三进制 → 十进制` | 输入三进制数，输出十进制 | — |
| `Ternary: 转换选中内容` | 自动识别方向，转换编辑器中的选中文本 | `Ctrl+Shift+T` |
| `Ternary: 打开计算器` | 打开交互式计算器面板 | — |

- **右键菜单**：选中文本后右键 → `Ternary: 转换选中内容`
- **状态栏按钮**：点击状态栏的「三进制转换」快速转换当前选中内容
- **循环节标记**：三进制输入/输出支持 `()` 标记无限循环部分，如 `0.(1T)` = 0.25

## 开发

```bash
cd extension
npm install
npm run compile
```

按 F5 在扩展开发主机中启动调试。
